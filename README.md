# Python Assignment 1 – Data Structures: Strings & Tuples
📌 Project Overview

This project is a Python fundamentals assignment focused on Strings and Tuples.

The assignment demonstrates basic Python operations such as:

String concatenation
String indexing
String slicing
String reversal
String methods
Tuple creation
Tuple concatenation
Tuple repetition
Tuple indexing and slicing

The main objective is to understand how strings and tuples are created, accessed, modified through supported operations, and processed using Python's built-in methods.

🎯 Objectives

The objectives of this assignment are:

Understand string concatenation using the + operator.
Accept user input using the input() function.
Access individual characters using string indexing.
Extract portions of a string using slicing.
Reverse a string using slicing.
Use built-in string methods such as:
upper()
lower()
capitalize()
count()
replace()
Create and combine tuples.

📝 Conclusion

This assignment provided practical experience with fundamental Python data structures, particularly Strings and Tuples. The exercises demonstrated how to manipulate strings using concatenation, indexing, slicing, and built-in methods. Tuple operations such as concatenation, repetition, indexing, and slicing were also implemented.

The assignment helped build a strong foundation in Python programming and basic data structure operations.
Repeat tuple elements using the * operator.
Access individual tuple elements using indexing.
Extract elements from tuples using slicing.
